# BiblioSoftware - Library Management System

A Python command line application designed to handle book inventory, lending operations, and catalog statistics for a library.

## Features
- **Catalog Management:** Add new books, update existing copy counts, and remove titles from the catalog.
- **Lending & Restocking:** Real-time loan processing with automatic stock decrement, plus inventory restocking.
- **Availability Check:** Instantly query whether a book title is currently in stock.
- **Summary Analytics:** Computes the total number of distinct titles, total copy count, and the average number of copies per book.
