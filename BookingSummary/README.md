# Booking Summary Report Automation

A Python script using pandas to aggregate and report transaction-level booking data.

## Features
- Ingests booking transaction records.
- Aggregates key business metrics grouped by city:
  - Total revenue (`totale_ricavi`)
  - Booking volume (`numero_prenotazioni`)
  - Average booking price (`prezzo_medio`)
- Exports clean reporting outputs directly to a CSV file.

## Requirements
- pandas
